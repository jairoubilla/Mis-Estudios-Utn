[TEORÍA AVANZADA]

En ciencias de la computación, un programa opera asignando, almacenando y transformando datos en la memoria. Python es un lenguaje de tipado dinámico y fuertemente tipado.

 ° Tipado dinámico: No es necesario declarar el tipo de dato que contendrá una variable al crearla; su tipo se determina en tiempo de ejecución.

 ° Fuertemente tipado: El lenguaje no permite tratar a una variable como si fuera de un tipo distinto al que tiene sin una conversión explícita. Intentar sumar  texto y números sin conversión causará un error crítico.
  
Los tipos de datos básicos fundamentales en Python son:

  1. Números: int (enteros sin decimales) y float (reales o de coma flotante).
  
  2. Cadenas de texto (str): Secuencias de caracteres encerradas entre comillas simples o dobles.
  
  3. Booleanos (bool): Valores lógicos que solo pueden ser True (cierto) o False (falso).

        tasa_encriptacion = 1.25     # Tipo: float
