# 🏥 Proyecto Hospital - Resumen Ejecutivo

## Para Decisores en 5 Minutos

### ¿Qué es?

Un **sistema de gestión de turnos médicos profesional, seguro y escalable** desarrollado con Flask (Python) y React (JavaScript). Permite a pacientes agendar citas y a médicos gestionar sus horarios.

### ¿Por qué usarlo?

✅ **Seguridad de Grado Empresarial**
- Autenticación JWT + contraseñas hasheadas
- Cumplimiento HIPAA/GDPR (roadmap)
- Auditoría de todas las acciones

✅ **Código Profesional**
- 50+ tests automáticos
- Documentación exhaustiva
- Arquitectura escalable

✅ **Listo para Producción**
- Docker + Kubernetes ready
- Deployment AWS + Docker
- Monitoreo y alertas incluidos

**Backend:** Flask 3.0 + Python 3.8+
**Frontend:** React 19 + Vite
**BD:** SQLite (dev) → PostgreSQL (prod)
**Auth:** JWT + Bcrypt
**Testing:** pytest 7.0+
**Deployment:** Docker, AWS, Kubernetes
