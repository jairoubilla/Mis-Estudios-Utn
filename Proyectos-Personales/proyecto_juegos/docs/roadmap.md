# Roadmap

## Phase 0: Foundations

- Learn Git and GitHub basics.
- Install Godot 4.x.
- Install VS Code and Godot extension.
- Create first 3D scene.
- Move a character with keyboard and mobile joystick.

Deliverable: one character moving in a test map.

## Phase 1: Offline Combat Prototype

- Add third-person camera. Done.
- Add HP component. Done.
- Add enemy dummy. Done.
- Add basic attack. Done.
- Add XP and level data.
- Add local save/load.

Deliverable: 5-minute offline combat demo.

## Phase 2: First Online Prototype

- Run local backend with Docker.
- Add login.
- Create character.
- Sync two players in the same zone.
- Add chat.
- Persist character position and XP.

Deliverable: 2-10 players connected locally.

## Phase 3: MMO Vertical Slice

- Add one city.
- Add one PvE zone.
- Add one dungeon.
- Add party system.
- Add basic loot.
- Add one world event.
- Add clan prototype.

Deliverable: closed alpha for 20-50 testers.

## Phase 4: Mobile Production

- Android export.
- iOS export preparation.
- Performance profiling.
- Touch UI polish.
- Crash reporting.
- Analytics.
- Economy tuning.
- Ethical VIP and battle pass.

Deliverable: beta test build.
