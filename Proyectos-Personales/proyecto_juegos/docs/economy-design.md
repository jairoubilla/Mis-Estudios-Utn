# Economy Design

## Currency Types

| Currency | Source | Use |
| --- | --- | --- |
| Gold | Gameplay | Repairs, crafting, marketplace, travel |
| Crystal Tokens | Free events | Basic cosmetics and event rewards |
| Premium Gems | Real-money purchases | Cosmetics only |
| Honor | PvP | PvP cosmetics and titles |
| Reputation | Factions | Recipes, cosmetics, access to vendors |

## Economy Rules

- Power progression comes from gameplay.
- Premium currency does not buy combat strength.
- Marketplace uses gold only.
- Listing and sale taxes reduce inflation.
- Important currency changes are logged server-side.
- New accounts have trading limits to reduce fraud.

## Gold Sinks

- Repairs.
- Crafting fees.
- Marketplace taxes.
- Travel fees.
- Cosmetic housing/decorations.
- Guild visual upgrades.
